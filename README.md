## ✨ Features

- **VS Code Editor Shell**: Authentic developer workspace interface with Explorer tree, file tabs, status bar, and breadcrumbs.
- **Embedded Copilot AI Assistant**: Built-in AI assistant powered by Groq API (`llama-3.3-70b-versatile`) with multi-tier fallback (Gemini, OpenAI) and an offline instant knowledge engine.
- **Interactive 3D Glowing Monogram Ball**: Floating radial-glow emblem with dynamic levitation and interactive visual state.
- **Dynamic File Tabs & Store**: Persistent tabs with preview vs. pinned tab modes, tab restoration, and smooth navigation.
- **Quick Open Command Palette (`Ctrl + P`)**: Real-time fuzzy-matching file search.
- **Theme Ecosystem**: 6 built-in themes (Durgesh Dark, Kyoto Sakura, Tokyo Night, GitHub Dark, Dracula, Nord).
- **Projects Showcase**: Detailed engineering summaries and live links to:
  - **Spark AI 2.0**: In-browser autonomous IDE with WebContainers & Vector Search RAG.
  - **TripFlow Lakehouse Pipeline**: Bronze-Silver-Gold Delta Lake data pipeline with PySpark.
  - **IOCL LogDigitizer Engine**: Zero-Shot OCR extraction & offline conversational AI platform.
  - **Digital Maintenance Logbook**: Offline-first laboratory equipment tracking system.

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure Environment Variables (Optional)

Create a `.env` file based on `.env.example`:

```env
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=llama-3.3-70b-versatile
```

*(Note: The embedded Copilot includes an offline local knowledge engine that answers all resume questions even without an API key).*

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### 4. Run Unit Tests

```bash
npm test
```

### 5. Production Build

```bash
npm run build
```
